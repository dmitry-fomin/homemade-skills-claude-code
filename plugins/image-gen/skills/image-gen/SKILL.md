Скил — это труба до модели: «промпт → PNG на диске» и обтравка готового файла. Картинки получаются
не из-за трубы, а из-за промпта и постобработки, поэтому половина ценности здесь — в предупреждениях ниже
и в [references/prompting.md](references/prompting.md).

Скил **не** делает: композицию атласов, ресайз, упаковку в WebP, ключевание по цвету, оценку качества.
Это снаружи — `magick`, `cwebp`, свои скрипты.

## Точка входа

```bash
uv run ${CLAUDE_SKILL_DIR}/scripts/generate_image.py <подкоманда> [флаги]
```

`${CLAUDE_SKILL_DIR}` подставляется харнессом и в теле, и в `allowed-tools` — за счёт этого запуск
не спрашивает прав и работает откуда угодно: из плагина, из личного или проектного каталога скилов.
Абсолютные пути вроде `~/.claude/skills/...` сюда не подставляем: у скила, установленного плагином,
такого пути нет.

`uv run` обязателен: зависимости объявлены инлайн (PEP 723), в системном python3 их нет.
`uv run --with rembg` не используем никогда — он тянет зависимости минут десять на каждый вызов.

Ключи берутся из окружения (`~/.zshenv`): у `--gpt` это `CLOSEROUTER_SO_API_KEY` (CloseRouter), у `--qwen` —
`OPENROUTER_API_KEY`. Нет ключа выбранного движка — скил падает с кодом 2, не сделав ни одного сетевого
запроса. Ключ не печатается никуда.

## Промпт пишем по-английски

Модель держит английский точнее: на русском промпте она чаще теряет ограничения композиции и
дорисовывает лишнее. В нейросеть уходит английский текст — **всегда**, независимо от языка разговора.
Если человек описал сцену по-русски, ты переводишь описание на английский сам и уже перевод кладёшь
в `--prompt`/`--prompt-file`. Комментарии, решения и разбор результата — по-русски.

## `generate`

| Флаг | Значение |
| --- | --- |
| `--prompt TEXT` | текст промпта (по-английски) |
| `--prompt-file PATH` | промпт файлом — кавычки не съедаются shell'ом; для длинных промптов только так |
| `--out PATH` | куда положить PNG; каталоги создаются, существующий файл перезаписывается молча |
| `--size WxH` | `1024x1024` (умолчание), `1024x1536`, `1536x1024`, `auto`; значение вне списка — код 2 |
| `--reference PATH` | референсный кадр, флаг повторяемый |
| `--gpt` | `openai/gpt-image-2` через CloseRouter — умолчание, лицо и персонажа по референсу держит лучше всех |
| `--qwen` | `qwen/qwen-image-3-pro` через OpenRouter — только когда человек попросил qwen |
| `--no-fallback` | запретить подмену движка |
| `--transparent` | прогнать результат через `rembg` перед записью |
| `--n K` | K кадров за вызов, суффиксы `-1..-K` |
| `--dry-run` | напечатать собранный запрос и модель, в API не ходить |

Флаги движка взаимоисключающие. Движки, их слаги и порядок фолбэка лежат таблицей в
`scripts/engines.conf` — **смена модели** это правка одной строки там, скрипт трогать не нужно.
А вот **новый движок** одной строкой конфига не заводится: под него нужен свой флаг, то есть правка
`pick_chain()` и `build_parser()` в скрипте. Фолбэк идёт строго вниз по списку: `--gpt` → `--qwen`,
а при `--qwen` (последняя строка) подменять уже не на что. `IMAGE_GEN_MODEL=<slug>` переопределяет слаг на один запуск.

В stdout — **один JSON и ничего кроме него**; прогресс, предупреждения и ошибки в stderr.
При любой ошибке stdout пуст, а в stderr уходит строка `error: ...` — парсить stdout можно только
после проверки кода возврата.

Один кадр (`--n 1`, умолчание) — поля описывают этот кадр:

```json
{"path":"assets/gen/pan.png","model":"openai/gpt-image-2",
 "requested_model":"openai/gpt-image-2","fallback":false,
 "size":"1024x1536","reference_used":true,"transparent":false}
```

Серия (`--n K`, K > 1) — метаданные лежат по кадрам в `paths`, потому что кадры серии могут
разъехаться по моделям. Верхнеуровневого `model` тут нет нарочно: он был бы враньём про часть кадров.
Верхний `fallback` — агрегат «хоть один кадр подменён», ровно то, что проверяют в приёмке серий;
`path` — первый кадр, оставлен для совместимости.

```json
{"path":"assets/gen/pan-1.png","requested_model":"openai/gpt-image-2",
 "fallback":true,"size":"1024x1536","transparent":false,"n":2,
 "paths":[{"path":"assets/gen/pan-1.png","model":"openai/gpt-image-2",
           "fallback":false,"reference_used":true},
          {"path":"assets/gen/pan-2.png","model":"qwen/qwen-image-3-pro",
           "fallback":true,"reference_used":true}]}
```

Коды возврата: `0` — файл записан; `1` — ошибка API или фолбэк запрещён флагом; `2` — ошибка аргументов,
окружения или непредвиденный сбой (битый ответ, отказ записи, падение `rembg`). Рядом с `--out` копится
журнал `.image-gen.log`: модель, размер, референсы, хэш промпта — по нему через месяц видно,
чем нарисован файл.

## `remove-bg`

```bash
uv run ${CLAUDE_SKILL_DIR}/scripts/generate_image.py remove-bg --in SRC --out DST
```

Флаги именно `--in`/`--out`. Подкоманда полезна и сама по себе, и как готовое окружение с `rembg`:
маски кладут рядом с исходником как `<имя>.rembg.png` и дальше ведут в свой матинг.

## Четыре предупреждения, каждое куплено браком

1. **`--no-fallback` во всех сериях, где кадры должны быть одной манеры.** По умолчанию при
   недоступности модели (429, 5xx) скил уходит на следующую вниз по списку и продолжает работу; подмена
   видна полем `fallback` кадра и строкой в stderr. На 400/401/402/403/404/422 подмены не будет —
   скил обрывается с кодом 1: это отказ по запросу, ключу или счёту, и другой движок его не лечит. Но лист, нарисованный другой моделью, — другой кот и другая бумага, якорь ломается
   тихо. Хуже: на `--qwen` лицо с референса держится слабо — персонаж выходит другим человеком.
   В приёмке серий стоит `fallback: false`.
2. **`--transparent` не использовать там, где нужен мягкий край.** `rembg` даёт бинарную обтравку
   keep/discard по каждому пикселю: резкий край «как у наклейки», белая бахрома, выеденные светлые
   участки внутри силуэта. Его выход годится только как жёсткая внутренность, вокруг которой альфа
   добирается матингом (см. справочник, раздел «Край»).
3. **Референс сохраняет лицо только на `--gpt`.** Замер на одном портрете: gpt-image-2 через CloseRouter
   дал того же человека в новой сцене, qwen-image-3-pro через OpenRouter — другого, при
   `reference_used: true`. Это поле значит «картинка ушла в запросе», а не «модель её учла». Схема
   «эталонный кадр → референс в каждый лист» живёт на `--gpt`.
4. **Заказанный в промпте цвет фона приходит не тем.** Замер (на seedream, прежнем движке): заказан `#FF00FF`, получен
   `srgb(205,29,153)`, и не плашкой, а с градиентом по кадру. Цвет в промпте — это цель, а не обещание,
   что такой пиксель есть в файле. Цвет подложки для постобработки берём **с самой картинки**
   (медиана по рамке), а не из константы промпта.

## Прежде чем генерировать серию

Открой [references/prompting.md](references/prompting.md) — там приёмы, купленные браком на реальных
партиях: композиция ставится выше стиля и дублируется трижды; промпт собирается из блоков-файлов;
character-lock не существует, поэтому рисуем листом на 6–8 поз; сетку с модели снимаем полностью;
фон под вырезку выбирается замером, а не на глаз; числовые критерии приёмки края и фона.
Без него следующая партия повторит те же ошибки.

## Типичные ошибки

| Симптом | Причина и что делать |
| --- | --- |
| `error: нет ключа: переменная ... не задана` | ключи живут в `~/.zshenv`; открыть новую сессию или экспортировать переменную |
| stdout не парсится через `jq` | в stdout попало лишнее — значит, что-то печатается мимо скила; сам скил пишет туда только JSON |
| половина промпта потерялась | кавычки съел shell — перейти на `--prompt-file` |
| кадр вышел в чужой манере | `fallback: true` в JSON: сработала подмена движка, перегенерировать с `--no-fallback` |
| `--reference` будто не влияет, лицо чужое | кадр нарисован на `--qwen` (сам или фолбэком); перегенерировать на `--gpt` с `--no-fallback` |
| первый запуск идёт минуты | uv собирает окружение с `rembg`/`onnxruntime`; дальше берётся из кэша |
| первый `--transparent` висит после сборки окружения | `rembg` тянет веса `u2net` (~176 МБ) в `~/.u2net`; один раз, дальше из кэша |
| Bash отвалился по таймауту, файла нет | подними таймаут Bash: дефолт 120 с, а один вызов — до `REQUEST_TIMEOUT=300` с × 4 попытки × движки цепочки; на серию и `--transparent` закладывай минуты |
| `error: движок ... отказал. HTTP 402` | кончились средства у провайдера этого движка (CloseRouter у `--gpt`, OpenRouter у `--qwen`); подмены на 402 нет |
| `HTTP 429` от `--gpt`, `image_upload_capacity` | CloseRouter временно не принимает загрузку референсов; скил сам повторит трижды, дальше — повторить позже |
| stdout пуст, код возврата 2 | непредвиденный сбой; текст в stderr, подробный traceback — `IMAGE_GEN_DEBUG=1` |
